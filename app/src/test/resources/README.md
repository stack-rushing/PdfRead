# 测试夹具说明

这个目录里的两个文件用于**算法回归测试**，都不是书籍内容。

## `cambridge_ocr_strips.tsv`

剑桥小说馆 2 级 08《真爱无界》(*Different Worlds*) 全 91 页、**页面顶部 20% 条带**（缩到 720px 宽）
的 OCR 识别结果。格式：

```
p000<TAB>第一行<U+0001>第二行<U+0001>...
p001<TAB>...
```

`OcrChapterBuilderTest` 每次构建都会重放这份真实识别结果，断言
`HeadingDetector` + `OcrChapterBuilder` 能从 OCR 的错字（`Afier`、`TransIation`、`Chapter 乥` 等）
里仍然还原出正确的 11 个章节及其页码。

之所以用**真实 OCR 输出**而不是手写样例：这些错字是真实数据逼出来的规则，
手写样例只会验证「我以为的错误」。

## `chapters-cambridge.json`

同一本书的目录成品（19 条：5 前置 + 11 章 + 3 后置），供测试验证
「导出的 JSON 能被 App 重新导入」。
